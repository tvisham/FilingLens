# Golden set

JSON Lines files read by `filinglens eval run`. Written by tools, reviewed by a person.
Nothing here is generated by an LLM.

| File | Written by | Counts toward a metric when |
|---|---|---|
| `financials.jsonl` | `eval snapshot` (pipeline values), then `eval label financials` | `verified_by` is set |
| `cadence.jsonl` | `eval snapshot`, then `eval label cadence` | `verified_by` is set |
| `risk_labels.jsonl` | `eval label risk TICKER` | always (each row is a human label) |
| `coherence_labels.jsonl` | `eval label coherence REPORT.json` | always |

Risk labels are keyed by accession + a hash of the factor heading, so they survive
re-ingestion. Use the taxonomy slugs: macro, regulatory, cyber, supply_chain, competition,
litigation, ai_technology, liquidity, esg_climate, other.
